# chronos-curated-release
Conditional research and signed certificates. No universal theorem or SAT hardness proof is asserted.

## Download and verify

Download `chronos_authorized_candidate.zip` and `chronos-release.zip.sha256` from the [Chronos Curated Research Snapshot](https://github.com/inaciovasquez2020/chronos-curated-release/releases/tag/snapshot-2026-11-01). In the download directory, run:

```bash
shasum -a 256 chronos_authorized_candidate.zip
```

Compare the complete 64-character digest with the digest in `chronos-release.zip.sha256` before extracting the archive.
